Note l’état de chaque disque : l’estimation se recalcule aussitôt, galette par galette et pour l’ensemble du bac. Application installable, utilisable sans connexion.

Première utilisation : importe ta collection. Cette application est publiée sans aucune donnée personnelle — ta collection ne se trouve nulle part sur internet. Charge le fichier ma-collection.json que Claude t’a envoyé dans la conversation : il sera enregistré sur cet appareil uniquement, et l’application sera prête, y compris hors ligne.

Tu peux aussi charger un export CSV de Discogs, mais sans les estimations de valeur : elles ne figurent que dans le fichier JSON.

    Comment l’estimation est calculée

    Une fourchette indicative, pas une expertise. Le point de départ de chaque disque est sa valeur en état Near Mint, d’après ma connaissance générale du marché — sans accès aux ventes en cours. Cette base est pondérée par l’état que tu saisis, selon les coefficients ci-dessous, en comptant le disque pour 75 % et la pochette pour 25 %. Pour des chiffres réels, la valeur estimée de ta collection sur Discogs, calculée sur les ventes effectives, reste la référence.
